# 身态马来语商品 Listing 制作

将产品卖点、同款中文参考图、实物和指定模特转成可核对的一套商品图。2405 是已定稿案例。以下是品牌默认做法，用户指定的款、市场、尺寸、视角和交付范围优先。

## 1. 锁定输入和画面事实

- 先确定款号、销售渠道、选定色款、SKU 色名、目标语言及此次要做的图。接收商品卖点文字或表格、中文主图及长详情、同款实物和局部特写、原始尺码表、模特原图或虚拟模特母版。客户给的标准文档只控制流程和示例构图。
- 把每张输入标为产品事实、展示视角、模特身份、文案数据或风格参考。对比原图、色名、包覆、纹理、走线及袖口等结构。记录每条卖点的实物出处、可见事实、马来语表达及要落的图位。
- 对真人或手部使用源图锁定编辑，保留脸、体态、姿势和裁切。虚拟模特使用确认的同一母版作为唯一身份参考，允许按脚本生成新姿势。在身份母版不足以支持指定角度时，标明缺证。其他款参考图上的人物和商品仅能转述为构图要求，不能喂给模型作为替代身份或商品。
- 在售色必须各有同款实物来源。产品图片能证明可见结构，不能单凭照片证明透气率、抗菌、长时间不卷边或不移位。无法证实的强口径用可见结构或经确认的设计意图替代。尺码与单位直接核对原表。

## 2. 先排整套图，再逐张做

默认 8 张 1080×1080 主图和 9 张 1080×1920 独立详情页。SKU 每个在售颜色一张清楚的单品白底原图，单独归档。指定比例、平台尺寸或页数不同时按该次要求调整。只有可证明该款卖点的图位才进入方案。

| 顺序 | 主图 | 详情图 |
| --- | --- | --- |
| 01 | 指定模特正面或有表现力的上身，突出款式 | 视觉开篇，突出代表卖点，可给单穿和内搭示例 |
| 02 | 同一款同一色的侧面和背面 | 尺码与量法，可同时展示胸围、下胸围等核对值 |
| 03 | 有证据的肩带、开口或后背结构 | 对应在售 SKU 色名的颜色集合 |
| 04 | 材质、杯垫或关键局部 | 主卖点的近景与解释 |
| 05 | 对比示意或明确的贴合问题 | 对比结构、回答痛点，明确标为示意 |
| 06 | 第二个购买决策，例如单穿和叠穿 | 同色正、侧、背三视角 |
| 07 | 选色集合 | 杯垫、里层或独立工艺特写 |
| 08 | 尺码 | 面料、网纱及穿着触感的已证实信息 |
| 09 |  | 走线、下摆等收尾结构特写 |

- 每张主图用一个买家问题、一个主卖点和能证明它的视角。详情按手机阅读顺序重新组织信息，从中文原始详情、实物及数据独立做页；不用定稿主图改成竖图冒充详情。必要时拆成两页，既要看得清，也要有新增信息。
- 记录图位、用途、原图、产品与身份参考、精确的目标文案、尺寸及禁改部分。对生成任务使用 `set_policy.profile: shentai-ms`，按 [证据字段](evidence-schema.md) 记录原图来源类别与虚拟模特。白底 SKU 另记原图、色名、文件和核验状态，不计入主图/详情数量。
- 按用户指定的图像工具执行；未指定时沿用适用的源图编辑路线。每个任务写清哪些参考只控制身份、结构、视角或数据。真实花纹、缝线、色泽和其他商品细节优先。优先使用已有、确认过的同款白底单品；缺少时保留缺项，不能从促销拼图、包装图或生成结果推断在售白底 SKU 已齐。

## 3. 逐张审核，连起来看

- 实物关：对照同款和同色的原图核对颜色、轮廓、纹理、透感、连接处和实物细节。型号、尺码、构造错一处就修对应图位。
- 模特关：真人锁源逐处比对，虚拟模特比较脸、发型、体态及视角；整套统一。一张验收失败时回看整套影响，实际只重做受影响图。
- 文案关：以马来语为准，读 OCR 后再逐字目视，尤其色名、单位、小数、数字和相似字母。按品牌当次要求处理原品牌字样和款号。2405 的决定是正文去掉旧品牌和款号，只有主图在右上角加确认的透明皇冠图形，详情和 SKU 不带图形。不要把单款要求套成所有项目的默认 Logo。
- 整套关：主图做并排审核总览，检查标题系统、边距、标志和图面信息重复。详情保留逐页文件，另按顺序等宽拼一张单列供审核，用手机宽度回看首尾衔接、字号、断行和空白。单列预览不作为逐页上传素材。
- 通过后制作图文 PDF。逐张列出类别、图位、用途、画面表达和卖点，放入同一版本的图片；首页可导航，另有卖点与图位对照表。确认期的文件作为候选交付，用户要求修订时重验有改动的图、目录与 PDF 对应关系。

## 4. 定稿归档和证据

用户确认或明确要求归档后，从其选定版本按字节复制。先校验来源路径和 SHA-256，保留已有历史与中文原图。身态项目的马来语本地归档位于项目根目录：

```text
马来语商品图片定稿/
  <款号>/
    主图/
    详情图/
    SKU 白底图/
    <款号>_商品图片说明.pdf
  归档索引.md
  归档来源.json
```

已确认的独立尺码图放在详情图组。白底 SKU 缺项时保留目录并标明。归档记录包括款、类别、图位、来源、版本、尺寸、SHA-256；核对图片数量、PDF 目录和嵌图与归档一致。不同语言、店铺及渠道的定稿不可混用。本地归档不触发平台上传；正式库原位替换和后台提交各按对应授权执行。

## 5. 2405 对照示例

雪兰花 V 领与交叉美背看详情 04，宽肩带看详情 05，连体打孔杯垫看详情 07，细网纱看详情 08，杯下走线和双折下摆看详情 09。黑色与珍珠白分别使用同款白底实物源。首尾详情修订时只替换实际两页，再按同一顺序重新检查手机预览和说明 PDF。完整本地定稿共 8 主 / 9 详情 / 2 SKU。例子的产品事实、色名、虚拟模特和位置规则仅适用于该试例。
